Algorithme Régression linéaire

Détails :

Une Régression Linéaire est un algorithme de machine learning supervisé utilisé pour prédire une variable continue à partir d'une ou plusieurs variables explicatives. Son objectif principal est de trouver la meilleure droite (ou hyperplan dans le cas multivarié) qui ajuste les points de données tout en minimisant l'écart entre les valeurs prédites et les valeurs réelles. Cette droite est définie par des coefficients (pentes) et une constante (ordonnée à l’origine) qui représentent l’influence de chaque variable explicative sur la variable à prédire. En résumé, la régression linéaire cherche à modéliser la relation linéaire entre les variables pour pouvoir prédire de nouvelles valeurs de manière simple et efficace.

Caractéristiques :

  • Prédiction de valeurs continues
  • Minimisation de l’erreur
  • Simplicité et rapidité
  • Facilité de visualisation
